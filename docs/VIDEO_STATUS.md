## Что было исправлено

1. **Сборка pjproject с видео** — `--with-ffmpeg=/usr` + v4l2 (openh264, vpx).
   `PJMEDIA_HAS_VIDEO=1`, в `_pjsua2.so` — `H264/97`, `H263-1998/96`, `VP8/102`.
2. **`_configure_video_codecs`** в `SipEngine`: приоритеты видео-кодеков
   выставляются через `ep.videoCodecEnum2()` / `ep.videoCodecSetPriority()`.
3. **`AccountVideoConfig`**: `autoTransmitOutgoing`, `autoShowIncoming`.
4. **`videoCount=1`** в `CallOpParam` при accept/call.

## Известные проблемы GUI (тайл «Своя камера»)

Из пользовательских отчётов (требуют проверки на целевом железе):

* изображение в тайле «Своя камера» **не подстраивается под размер** тайла
  при изменении сетки;
* при **смене устройства** (виртуальная камера -> веб-камера) в тайле может
  оставаться старое изображение, хотя на стороне собеседника камера
  меняется;
* при **муте видео** тайл показывает последний кадр вместо заглушки;
* в сетке может быть **один видео-тайл** там, где ожидаются два (свой и
  удалённый).

Связано с `mcuclient/ui.py` (`ParticipantTile.attach_native_video`,
`resizeEvent`, `_rebuild_video_grid`, `_paint_vsource_frame`) и
`mcuclient/video_preview_service.py`. Тесты видео-пути зелёные, поэтому
причину искать в конкретном окружении/устройстве (см. `mcu-client.log`).
