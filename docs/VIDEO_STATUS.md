# Статус видео (Этап 4): блокер — нет видео-кодеков в сборке

## Факт (проверено)

`pjsua2.codecEnum2()` в текущей сборке возвращает **только аудио-кодеки**:

 

**Ни одного видео-кодека** (H264/H265/VP8/VP9/H263 отсутствуют).

При этом:
* `pjsua2.VideoMedia`, `VideoPreview`, `VideoWindow` — присутствуют;
* `vidDevManager().getDevCount()` = **4** (устройства видны);
* конфиг и UI содержат настройки видео (разрешение, fps, битрейт).

## Вывод

Кодовая база **готова к видео**, но **текущая сборка pjproject собрана без
видео-кодеков**, поэтому видео-звонок технически невозможен: SDP не предложит
видео, `vidSetStream` не даст потока.

## Что требуется для реального видео

Пересобрать pjproject с видео:

 

нужны: `libavcodec/libavformat/libavutil/libswscale`, `libv4l-dev`, `libyuv`.

## Варианты

1. **Пересобрать pjproject с видео** (долго, ~20–40 мин; в контейнере может
   не найтись FFmpeg-dev или видео-устройств для реальной проверки).
2. **Заморозить видео** (как H.323) и продолжить с чатом/другими фичами.
3. **Проверить видео-путь косвенно**: юнит-тесты на `set_video_quality`,
   `vidSetStream`-ветки, выбор кодека — без реального медиапотока.

Рекомендация: **вариант 3 сейчас** (дешёво, без сборки) + **вариант 1** как
отдельная инфраструктурная задача; H.323 и видео — заморожены до неё.
