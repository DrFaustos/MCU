## 2. Wayland: видео в тайлах

pjsua2 рендерит видео через native window handle (XID на X11, HWND на Windows).
На Wayland такого handle нет → тайлы пустые. Решение: запускать Qt через
XWayland (`QT_QPA_PLATFORM=xcb`). Это делается автоматически в `run.py`
до создания `QApplication` (модуль `mcuclient/qt_platform.py`).

Управление через переменную окружения `MCU_QT_PLATFORM`:

| Значение   | Поведение                                              |
|------------|--------------------------------------------------------|
| `auto`     | (по умолчанию) Wayland → xcb, X11/Windows не трогаем   |
| `xcb`      | принудительно XWayland/X11                             |
| `wayland`  | принудительно Wayland (видео не будет)                 |
| `native`   | не вмешиваться                                         |

 

Если XWayland недоступен, в лог пишется явное предупреждение.

## 8. Полезные флаги run.py

| Флаг                  | Назначение                                   |
|-----------------------|----------------------------------------------|
| `--doctor`            | диагностика окружения и выход                |
| `--headless`          | без GUI                                      |
| `--call URI`          | headless: позвонить и выйти                  |
| `--call-wait N`       | сколько секунд ждать вызова                  |
| `--null-audio`        | null-аудиоустройство PJSIP (без реального звука) |
| `--auto-answer`       | автоматически принимать входящие             |
| `--list-video-devices`| список камер                                 |
| `--test-camera ID`    | превью камеры N секунд                       |
| `--no-camera`/`--no-mic` | старт с выключенными устройствами         |
